## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

业务流程里某个节点状态一变，好几个模块都要跟着做后续动作，现在这些调用是硬编码串起来的，加一个下游就得改一次主流程。请从零实现一个进程内事件总线，仓库里只有一个空的 Maven 工程（声明了 JUnit 5 与 AssertJ）。要求：1) 发布订阅：支持按事件类型订阅，且订阅父类事件也能收到子类事件；你的类型匹配规则需要写清楚并有测试；2) 分发模式：同步分发与异步分发两种，异步模式使用自研线程池并可配置队列容量与拒绝策略；3) 顺序保证：同一个聚合键（由发布者指定）的事件必须按发布顺序被消费，不同聚合键之间允许并行，需提供测试证明；4) 异常隔离：单个订阅者抛异常不得影响其他订阅者，失败需要记录并支持配置是否重试；5) 死信：重试耗尽后的事件进入死信队列，提供查询与手动重投接口；6) 事务同步：提供「事务提交后再发布」的钩子（可对接 Spring 的 `TransactionSynchronization`，也可自定义 SPI），保证事务回滚时事件不发出；7) `mvn -q verify` 跑通；8) README 说明类型匹配规则、顺序保证的范围、异常隔离与重试语义、已知限制。
